BGM Folder
==========

Put your audio/MIDI files here. Supported formats:
  - MP3, OGG, WAV, FLAC, M4A, AAC
  - MID, MIDI

The index.html BGM player will automatically list files from this folder
via bgm-list.php (requires Apache + PHP).

If PHP is not available, you can still use:
  - Local file upload
  - Direct audio/MIDI URL input
